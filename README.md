История Московского ипподрома

Тестовое задание. Проект представляет собой адаптивный блок истории Московского ипподрома с изображениями, текстовыми описаниями и анимациями появления элементов при прокрутке страницы.

## Технологии

- **Vue 3** — разработка пользовательского интерфейса.
- **TypeScript** — статическая типизация.
- **Vite** — сборка и локальный сервер разработки.
- **SCSS** — стилизация компонентов.
- **Tailwind CSS 4** — подключён в проекте.
- **Intersection Observer API** — отслеживание появления элементов в области просмотра.

## Функциональность

- Отображение исторических событий в виде последовательности карточек.
- Адаптивная компоновка для разных размеров экрана.
- Анимации появления изображений и декоративных элементов.
- Просмотр изображений в полноэкранном режиме (Lightbox).
- Закрытие полноэкранного просмотра по клавише `Escape` и клику вне изображения.
- Оптимизированные изображения в формате WebP.

## Требования

- Node.js — версия, совместимая с используемой версией Vite.
- npm.

## Установка и запуск

Клонируйте репозиторий и перейдите в директорию проекта:
git clone https://github.com/stopalo/moscow24.git
cd Moscow24

Установите зависимости:
npm install

Запустите сервер разработки:
npm run dev

Vite выведет локальный адрес, по которому будет доступно приложение.

## Сборка проекта

Для создания production-сборки выполните:
npm run build

Готовые файлы будут размещены в директории `dist/`.

Для локальной проверки production-сборки запустите:
npm run preview
